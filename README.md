A program that writes the most creative excuse a hardware wallet gives for refusing to sign a transaction at 3 AM — one line, 99 characters: its seed phrase is counting sheep, all twenty-four words of it, and none of them is your transaction.

## Run it

```sh
node main.ts
```

It writes one line of UTF-8 text to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Deterministic: no fetch, no randomness, no clock.
